# Notey

A simple markdown notes PWA. Plain textareas, no frills — your notes stay in your browser's local storage.

**[Open the app](https://mhebbel2.github.io/notey/)**

## Features

- Write notes in markdown (plain editor, no preview)
- Create, edit, delete notes — auto-saved to local storage
- Backup: export/import all notes as JSON
- Light/dark theme follows your system
- Installable, works offline

## Run locally

```bash
python3 -m http.server 8000
# open http://localhost:8000
```
